# Identity Service

A Spring Boot backend service responsible for user identity management.

## Purpose

This project is being built to understand and implement production-style backend concepts using Java and Spring Boot.

## Tech Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Security
- Spring Data JPA
- Hibernate
- PostgreSQL
- Docker
- Maven
- Git/GitHub

## Current Features

- User entity management
- Role-based user model
- User registration API
- Password hashing with BCrypt
- PostgreSQL database integration
- Repository layer using Spring Data JPA
